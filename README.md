# JobScope 

Product: https://sonnvu.github.io/jobscope-ui-v1/

JobScope is a full-stack SaaS platform that enables students and early-career professionals to analyze job market trends by exploring desired roles and industries using keyword-filtered LinkedIn job postings stored in a backend database.

The platform empowers users to identify in-demand skills, compare career paths, and discover industry trends through interactive visualizations, helping them align their skill development with real-world job requirements.
